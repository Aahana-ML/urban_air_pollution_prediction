# 🌍 Urban Air Pollution Prediction

A machine learning project focused on predicting urban air pollution levels using meteorological, atmospheric, and satellite-derived features.

This project was developed as part of a Zindi machine learning competition and explores ensemble learning, feature engineering, hyperparameter tuning, and stacked models for tabular regression.

---

## 📌 Project Highlights

* Feature Engineering using temporal and interaction-based variables
* Random Forest & Extra Trees ensemble models
* Neural Network (MLP) experimentation
* Optuna hyperparameter tuning
* Weighted Ensembling
* Stacked Ensemble Learning

---
